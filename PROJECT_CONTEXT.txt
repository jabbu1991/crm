  CRM_SETUP_KEY (generated, used once on first setup), CRM_SECURE_COOKIES=1, CRM_BEHIND_PROXY=1,

- Security: hashed passwords, CSRF tokens, login throttling, single-use invite/reset links,
  tenant isolation enforced in code AND by SQLite triggers, safe CSV export (no formulas).

3. CRM — WHO USES IT (MULTI-TENANT SaaS)
======================================================================
- Sold to client businesses for a monthly fee. Everyone logs in at the same address.
- Roles:
  * Super Admin (Jabbar / agency): manages client organizations, can open any client's
    workspace READ-ONLY (every visit is logged in that client's access log), exports everything,
    turns plan features on/off per client (WhatsApp templates, Digital catalogue).
  * Organization Admin (client owner): sees all leads of their organization, manages projects,
    products, staff, templates, catalogue, settings, Recycle Bin.
  * Staff: sees/edits only leads they created or that are assigned to them.
- Clients never see each other's data.
- Current real client example: STARWAY TECH HYDRAULIC (gate automation / hydraulic machines).

4. CRM — FEATURES (ALL BUILT AND LIVE)
======================================================================
Leads
- Fields: customer name, company/business name, phone, WhatsApp, email, place, district,
  state (Indian states list + other), country, project, products (multi), requirement,
  source, quality, buying possibility, priority, status, assigned staff, next follow-up, notes.
- "Created by" is recorded automatically and can never be changed.
- Statuses: New, Contacted, Interested, Follow-up, Quotation, Negotiation, Converted, Not Interested, Lost.
- Sources: Facebook, Instagram, Google Ads, YouTube, Website, WhatsApp, Referral, Walk-in, Phone Call, Other.
- Possibility High/Medium/Low; Priority Urgent/High/Normal/Low.
- Lead QUALITY (Hot/Warm/Cold) was REMOVED from every screen, filter, report and export on 17 Oct
  (owner's request). Old values are still stored in the database (column lead_quality), untouched.
- Lists: search (incl. company), filters, sorting, 15 per page by default (Show 15/50/100).
- Inline editing in lists (status, possibility, priority dropdowns save instantly) + ✏️ Edit.
  Each place has its own small save form (fixed 17 Oct: phone-card changes used to be ignored).
- Phone layout: each lead is a card (name, company, place, status, Call, WhatsApp, Edit, Delete);
  filters fold behind a "🔍 Filters" button. Computer: full table.
- Tick boxes + "select all": bulk change status/possibility/priority/source/follow-up date,
  assign to staff (admins), export selected, delete selected.
- Delete: admins any lead; staff their own/assigned leads. Deleted leads go to a Recycle Bin
  for 30 days (with products, follow-ups, history); admins can Restore or Delete forever.
- Duplicate warning, CSV import, CSV export, full activity history per lead.
- After saving a new lead the user lands on "Today's Leads" (India date, newest first, the new lead highlighted,
  "Today: N leads", big ➕ Add Lead). Staff: leads they added today; admin: whole organization + "Added by".
- Notes and Next follow-up are editable straight from every list (Leads, Today's, Follow-ups, Dashboard,
  State-wise, Product-wise; phone cards too). Saving notes from a list marks the current follow-up Done; a date
  given (or Tomorrow / +3 days / +1 week) becomes the next follow-up. Old notes text goes to the lead history.
  Follow-up date colours: overdue red, today orange.
- Computer lead tables: header row and Name column stay fixed; a horizontal scroll bar stays at the bottom of the screen.
- Admin "⚙️ List columns" (Dashboard button, /settings/list-columns): choose + order list columns and up to 4
  fields on phone cards, per organization. Default: Name, Phone, Place, Status, Notes, Next follow-up, Assigned to.
- Import page: "⬇️ Download template" (CSV with all accepted headings + one example row that the importer skips),
  help box with allowed values. Import also reads Project and Next Follow-up (YYYY-MM-DD) columns.
Other pages
- Dashboard (per role), Projects/Campaigns (end date optional), Products & Services,
  State-wise leads, Product-wise leads (interest vs ordered vs purchased tracked separately),
  Follow-ups (overdue/today/upcoming/completed), Reports, Export page (CSV/ZIP by role scope),
  Staff & Users, Organization Settings, Client Organizations (Super Admin).
- Organization name shown in the top bar with a coloured initial badge; tapping it opens the Dashboard.
- Follow-ups page, Dashboard "Follow-ups due" and "Recently added leads": WhatsApp, Call, Status change,
  Edit (and ✅ Done on follow-ups); phone shows cards.
Website enquiries
- The website contact form also creates a lead in the agency workspace (project "Website
  Enquiries", source Website), with rate limit + honeypot.

WhatsApp (free click-to-chat, no API)
- Pressing a lead's WhatsApp opens WhatsApp with the message filled in; the user presses Send.
- One-click rule: no template ON -> sends "Hi <name>,"; one template ON -> that one;
  several ON -> small menu of the ON templates with "👋 Hi only" at the bottom.
- Phone: opens the WhatsApp app. Computer: asks ONCE "WhatsApp app or Browser", remembered per
  browser (change in My Account). Browser mode opens a new tab each time (WhatsApp Web blocks
  reusing tabs); App mode (WhatsApp Desktop) avoids new tabs.
- Message is sent from whatever WhatsApp account is logged in on that phone/browser.
- Which template was opened is written to the lead history.
- WhatsApp Templates page: Company templates (admin), My templates (each user), Default
  templates (Super Admin; copied to every new client). Each row: ON/OFF, Edit, Delete.
  10 default English templates (Welcome, Missed call, Product details, Quotation, Follow-up,
  Meeting/Demo confirmation, Order confirmation, Thank you, Re-connect, Offer/Festival);
  all start OFF. Placeholders: {name} {company} {product} {my_name} {my_phone} {org_name} {catalog_link}.
- Switches: Super Admin per client (plan), Admin per organization, each user in My Account.
- My Account: "Contact number" (used for {my_phone}).

Digital Catalogue (built 16 Oct 2026)
- Public page per client: crm.realviewcreativestudio.in/c/<client code>, product pages,
  logo + about text, WhatsApp us / Call buttons (use the organization's phone number).
- Admin turns it on in Organization Settings (publish, about, logo). Products get photos (max 3,
  any size, auto-shrunk to ~60-200 KB JPEG), price (optional), YouTube link, brochure as a
  Google Drive link (no PDF upload), "Show in the catalogue" tick.
- {catalog_link} in a template gives each customer a personal link. When they open it, the lead
  history shows "📒 Customer opened the catalogue / viewed <product>" and the dashboard shows
  "🔥 Opened the catalogue in the last 24 hours" (good time to call).
- Super Admin can switch the catalogue off per client (plan).

4B. CAFE MODULE (built 24 Oct 2026, same CRM, same server)
======================================================================
- Super Admin sets each client organization's "Software type": CRM / Cafe / CRM + Cafe
  (organizations.app_type). Existing organizations are CRM. "CRM + Cafe" shows a CRM ⇄ Cafe switch in the top bar.
  Cafe-only organizations never see CRM pages (they are redirected to the cafe home).
- Code: cafe.py (helpers, permissions, settings, points engine, bill maths), cafe_admin.py (settings, menu design,
  QR, menu items, banners, tables), cafe_pos.py (billing screen, orders, KOT, bills, public menu, online order),
  cafe_people.py (customers, points, templates, expenses, analysis, CSV), cafe_charts.py (SVG charts),
  templates/cafe/*, static/cafe.css, static/menu.css. Amounts are stored in paise (integers). QR codes: segno.
- Staff permissions (tick boxes, role presets Cashier / Manager / Custom): bill, discount, cancel bill, old bills,
  online orders, menu, expense add, expense view, reports, customers, redeem points, adjust points, marketing,
  settings, staff manage. Admins have everything. Unticked menus are hidden.
- Settings: name, tagline, logo, cover, phone, WhatsApp, address, map, FSSAI; paper 58/80 mm/A4; bill prefix + footer;
  KOT on/off (+ KOT with takeaway bill); GST on/off, GSTIN, inclusive/exclusive, item-wise GST %;
  digital menu on/off; online order on/off + Dine-in/Takeaway/Delivery; loyalty, refer & earn, birthday switches.
- Menu: categories, items (photo auto-cropped square, under 50 KB), price, optional offer price with dates
  (only shown if given; "% OFF"; billing uses it), Veg/Non-veg/Egg, tags (Bestseller, New...), ON/OFF.
  Offer banners (photo 1200x500, under 50 KB, linked item, dates). No banner -> offer items become banners.
- Digital menu: crm.realviewcreativestudio.in/m/<code>; QR poster + PNG; per-table QR (?t=<table id>).
  Menu Design page: 6 ready themes, own colours, "pick colours from logo", Grid/List, font, button shape, live preview.
- Online order: cart -> type, name, WhatsApp, address/table, note -> Pending (sound + badge for staff) ->
  Confirm (KOT) / Reject (reason) -> Ready -> Billed. Customer status page updates itself. Pay at counter.
- Billing screen (/cafe/pos): Dine-in (table) / Takeaway / Delivery, customer lookup by WhatsApp with points,
  discount ₹/%, points redeem (Max button), Cash/UPI/Card, KOT / Hold / Bill & Print. Print page: Print,
  Save (PDF via print dialog), WhatsApp bill (text + public bill link /b/<token>), 58/80/A4.
  Bills list with filters + totals + CSV; cancel needs a reason (points reversed).
- Customers: by WhatsApp number; visits, spent, points history; filters (30 days not visited, top, points,
  birthday week, points expiring in 7 days, new); WhatsApp marketing templates with {name} {points} {menu_link}
  {referral_link} {cafe_name} (click-to-chat per customer; bulk auto-send needs WhatsApp API later).
- Points: % of bill or points per ₹X, 1 point = ₹value, min bill, min redeem, max % of bill, expiry days.
  Refer & Earn: points to both after the new customer's first bill. Manual +/- with reason.
- Expenses / other income with categories and bill photo; Analysis: income, expense, profit, daily line chart,
  expense category donut, Cash/UPI/Card, 6-month comparison, top items, staff-wise; CSV exports.
- Not built yet (ideas): online payment, WhatsApp API auto messages, inventory/stock, offline mode.
- All cafe screens are in ENGLISH (owner's request, 24 Oct). Owner discusses in Malayalam, software text stays English.
- Menu items have a serial number (S.No), auto 1, 2, 3... (editable, unique per cafe). Staff only: shown in Menu list,
  billing tiles, Excel. Billing: type S.No + Enter to add the item. NOT shown on the customer menu or bill.
- Bulk menu (Menu > Excel upload / photos): download empty template or current menu (.xlsx, openpyxl), upload ->
  preview (new / update / problem rows) -> Import. Match by S.No, else item name. New categories auto-created.
  Bulk photos: file name = item name or S.No (e.g. 'Kerala Chai.jpg', '12.jpg'), each cropped square under 50 KB.
- Demo: demo.bat creates "Chai Corner" (cafe_admin / cafe_cashier, password demo1234), menu at /m/chai.
