Bill & printer

🖨 Printer എങ്ങനെ set ചെയ്യാം?
  • Computer + USB/WiFi printer: printer-ന്റെ driver install ചെയ്യുക. Print window-ൽ ആ printer തിരഞ്ഞെടുക്കുക, Margins: None, "Headers and footers" off. ഒരിക്കൽ ചെയ്താൽ Chrome അത് ഓർക്കും.
  • Tablet/ഫോൺ + Bluetooth printer: Play Store-ൽ നിന്ന് "RawBT" (free) install ചെയ്ത് printer pair ചെയ്യുക. Bill-ൽ Print അമർത്തുമ്പോൾ printer-ന്റെ പട്ടികയിൽ RawBT തിരഞ്ഞെടുക്കുക.
  • Printer ഇല്ലെങ്കിലും Save (PDF), WhatsApp എപ്പോഴും പ്രവർത്തിക്കും.
